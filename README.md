# codex-app-server-java

Java client and protocol bindings for the Codex app-server JSON-RPC interface.

This project is intended to provide a small, framework-independent Java integration that:

- launches and communicates with `codex app-server` over JSONL/stdio;
- exposes typed thread, turn, item, approval, and notification APIs;
- preserves unknown methods and fields for forward compatibility;
- tracks the versioned schemas generated by the installed Codex CLI; and
- can serve as a candidate for future contribution to the upstream Codex project.

The API is not implemented yet. Initial development will be validated in LoopAide before the first release.
